# Python_Internship-Tasks


This repository contains four beginner-friendly Python command line projects:

## Projects

### 1. Simple Calculator
Features:
- Addition
- Subtraction
- Multiplication
- Division
- Input validation

### 2. Number Guessing Game
Features:
- Random number generation
- Multiple attempts
- High/Low hints
- Attempt counter

### 3. To-Do List
Features:
- Add tasks
- Delete tasks
- View tasks
- Menu-driven interface

### 4. Password Generator
Features:
- Random password generation
- Uppercase letters
- Lowercase letters
- Numbers
- Special characters

## How to Run

```bash
python calculator.py
python guessing_game.py
python todo_list.py
python password_generator.py
